## 1. Что это

Десктопное приложение **Kawaii Radio** (радио J-Pop / OST / Riot + чат + Kawaii ID) для Windows.
Стиль — «настоящее железо»: тактильный аппарат в духе Teenage Engineering × Braun, мел/графит, LCD, светодиоды,
термопринтер. Весь корпус — **рендер Blender (Cycles)**, поверх него живой HTML/JS-слой в окне **Tauri 2** (Rust).

Бэкенд уже существует (Cloudflare Worker в репо мобилки, `D:\kawaii_radio_app\cloud`), десктоп его только читает:

| Что | Где |
|---|---|
| Расписание эфира (все слышат одну секунду) | `GET https://radio.kawaii.uz/radio?station=jpop\|ost\|riot` |
| Треки, LRC-тексты (uzbek / romaji / kanji), описание `info` | `https://radio.kawaii.uz/playlist.json` |
| Чат (WebSocket: hello / welcome / msg / presence …) | `wss://radio.kawaii.uz/chat` |
| Стикеры | `https://radio.kawaii.uz/files/stickers/pack.json` |
| Ранги Kawaii ID | `https://id.kawaii.uz/api/v1/u/{username}` (поле `rank`: display_rank, display_label, image_url, season_xp, next_xp, next_label); картинки `https://id.kawaii.uz/static/img/ranks/{rank}.webp` |

Обложки отдаются с CORS `*`.

## 3. Как собрать

### 3.1 Тулчейн (на этом ПК уже лежит в `.tools`, на новом ПК — поставить заново)
- Rust 1.9x, таргет `x86_64-pc-windows-gnu`, линкер — WinLibs MinGW (`.tools/mingw64`).
- Blender 4.5 LTS portable: `.tools/blender-4.5.9-windows-x64/blender.exe`.
- Python 3 + Pillow (для конвертации PNG → WebP).

```bash
export RUSTUP_HOME=/d/kawaii_radio_exe/.tools/rustup CARGO_HOME=/d/kawaii_radio_exe/.tools/cargo
export PATH="/d/kawaii_radio_exe/.tools/cargo/bin:/d/kawaii_radio_exe/.tools/mingw64/bin:$PATH"
cd /d/kawaii_radio_exe/app && cargo build --release
cp target/release/kawaii-radio.exe "../Kawaii Radio/Kawaii Radio.exe"   # рядом ОБЯЗАТЕЛЬНО WebView2Loader.dll
```
`WebView2Loader.dll` берётся из `target/release/` после сборки (или из zip в `dist/`).

### 3.1b Установщик (NSIS, без прав администратора)
```bash
cargo install tauri-cli --version "^2" --locked     # один раз (~15 мин)
cd app && cargo tauri build                          # → target/release/bundle/nsis/Kawaii Radio_<ver>_x64-setup.exe
```
Версия — в `tauri.conf.json`, `Cargo.toml` и `const VERSION` в `ui/app.js` (держать одинаковой). Готовый
установщик кладётся в `dist/KawaiiRadio-<ver>-setup.exe`. WebView2Loader.dll установщик кладёт сам, WebView2 ставит сам.

### 3.2 Рендеры корпуса (≈2 мин на плиту на RTX, 4 плиты)
```bash
B=/d/kawaii_radio_exe/.tools/blender-4.5.9-windows-x64/blender.exe
cd /d/kawaii_radio_exe/design/blend
"$B" -b -P main.py -- --theme dark  --app        --scale 2 --out /tmp/dark-up.png
"$B" -b -P main.py -- --theme dark  --app --down --scale 2 --out /tmp/dark-down.png
# то же для --theme light
python -c "from PIL import Image; Image.open('/tmp/dark-up.png').convert('RGB').save('../../app/ui/assets/dark-up.webp', quality=94, method=6)"
```
Флаги `main.py`:
- `--app` — убрать всё, что рисует живой слой (тексты, обложки, LCD-контент, чек, чат).
- `--down` — все клавиши нажаты и все LED горят (из этой плиты JS вырезает «нажатое/горящее» состояние).
- `--scale 2` — 4K. `--samples N` — для быстрых тестов (`--samples 64` без `--scale` ≈ 30 с).
- `--flat` — выключить «премиум-проход» (фаски, скользящий свет, неровность глянца) для A/B.
- `--view agx` — AgX тонмаппинг (пробовали — тёмная тема слишком темнеет, оставлен Standard).
- Анимации: `--anim-print`, `--anim-scroll`, `--anim-chat`, `--anim-tv`, `--region x0 y0 x1 y1`.

**Быстрый A/B-тест:** рендер `--samples 96` без `--scale`, потом кропы через PIL и смотреть глазами (Read на png).

## 4. Как устроено (главное)

- **Координаты:** всё в дизайн-пикселях 1920×1080. В Blender 1 unit = 100 px, ортокамера, `P(x, y)` переводит.
  JS-слой использует те же координаты → хит-зоны совпадают с рендером пиксель в пиксель.
- **Клавиши:** `ctl(name, x0, y0, x1, y1, {cls, click})` в app.js создаёт хит-зону; внутри `.lit` — кусок
  `*-down.webp` (background-position), показывается при нажатии/включении. Значит, **если двигаешь деталь в main.py,
  поправь координаты её `ctl(...)` в app.js**.
- **LED:** тоже `ctl` с классом `led`, `on(el, bool)` включает. Свет диода — в рендере (материал `Ctx.led`:
  белёсая сердцевина → насыщенный край). CSS-ореол только слабый (`.ctl.led.on::after { opacity: .28 }`).
- **Тривижн** (обложка слева): CSS 3D, 24 трёхгранные планки, волна поворотов по 120°.
- **Дисплей текста** (справа, 610..1370 × 190..634): LRC-караоке; если текста нет — точечный спектр `#viz`.
- **LCD** (большая зелёная полоса) и **барабан тюнера** — canvas, рисуются в реальном DPR (резко).
  Барабан крутится только при смене трека/станции (`tick(n)`), постоянно НЕ крутится (пользователь просил).
- **Громкость:** ручка (колесо/перетаскивание) + кольцо из 21 LED.
- **VU / LEVEL:** WebAudio AnalyserNode.
- **TAVSIF:** термочек с описанием песни, печатается, прокручивается колесом (ручка-крутилка), двойной клик — оторвать.
- **Чат:** только чтение (без Kawaii ID), аватарки-глифы.
- **Экраны** 1 поиск, 3 библиотека, 4 профиль, 5 настройки — шторка `shutter()` опускается на дисплей текста.
- **Feel pass:** `sfx()` (звуки синтезируются WebAudio, без файлов), физика нажатия, цвет обложки подсвечивает отсек,
  блики стекла, загрузка «из темноты», помехи при перенастройке.
- **Горячие клавиши:** Space, 1/2/3, ↑/↓, L, T, M, Ctrl+F, F11, Esc.

## 5. История решений (что пользователь одобрил / отклонил)

Одобрено:
- Рендер устройства в Blender (CSS-макеты были «слишком простые»).
- Плоский тривижн-обложка слева + большой дисплей текста справа; шрифты «вариант 3» (Dela Gothic One, M PLUS Rounded,
  VT323/DotGothic16, Galmuri); TAVSIF-принтер с длинным чеком-свитком; анимированный чат; обе темы.

Отклонено:
- Джукбокс / проигрыватель пластинок («не наш бренд»), 3D-перспектива и лампы внутри окна обложки.
- Свечение при наведении на кнопки, постоянно крутящийся барабан, яркие «дешёвые» CSS-ореолы диодов.

Последняя оценка пользователя (2026-10-22): **идея нравится, исполнение — нет**: «панели как из игр 2008 года»,
диоды ненатуральные, не хватает текстур и проработки. Хочет уровень «настоящая предметная фотография».

   - исправлен z-fighting: полы углублений были в одной плоскости с дном выреза → диагональные «треугольники».

   - барабан сатиновый, без эмиссии-«свечения».
5. Живой слой: плёночное зерно + виньетка `#grain` поверх всего; спектр — круглые точки 64×30 как у VFD.
6. **Сканированные текстуры** (ambientCG CC0, `Ctx.pbr()`): Plastic013A — корпус/лотки, Plastic006 — графит,
   Plastic010 + Fingerprints002 — клавиши, Fingerprints002 — стёкла. Папка `design/blend/pbr/` НЕ в git —
   скачать `bash design/blend/fetch_pbr.sh` (без неё рендер работает, но без зерна). Выключить: `--nopbr`.
7. Выключенные LED — дымчатые тёмные линзы; LEVEL-индикатор аналоговый (частичная яркость + послесвечение).
8. Дисплей текста: сетка точек VFD, внутренняя тень от рамки; длинная текущая строка уменьшается и всегда
   влезает в 2 строки (раньше налезала на следующую). Светлая тема: подписи навигации тёмные, барабан не засвечен.

## 7. ЧТО ДЕЛАТЬ ДАЛЬШЕ (по приоритету)

### A. Визуальное качество (главная боль пользователя)
1. **Настоящие PBR-текстуры** (CC0: polyhaven.com, ambientcg.com): soft-touch пластик, шлифованный/анодированный
   алюминий (ручка, решётка), резина, отпечатки/царапины на стёклах (roughness-карты). Подключить в `lib.mat` как
   image-текстуры (box-проекция по Object coords). Сейчас всё процедурное — это главный источник «игрушечности».
2. **Зазоры и сборка:** у настоящих устройств панели вставлены с щелью 0.3–0.6 мм с тенью внутри. Сделать отсеки
   (bay, printer, chat, LCD) отдельными «вставками» с щелью по контуру, а не просто вырезами в монолите.
   Можно добавить винты Torx в углах печатающей головки / отсеков (места мало — аккуратно).
3. **Свет LED на корпусе из рендера:** в `--down` плите горящий диод уже светит на пластик, но слабо. Можно отдельным
   проходом (light groups / отдельная плита `-glow`) рендерить световое пятно каждого LED и показывать его в JS
   вместо CSS `::after`.
4. **Экраны:** LCD — тень сегментов на подложку (уже есть в JS), добавить подсветку подложки неравномерную,
   отражение корпуса в стекле. Дисплей текста — VFD-ощущение (свечение точек, лёгкая сетка).
5. **Светлая тема:** подписи на навигационных клавишах (ASOSIY, QIDIRUV…) бледные — поднять контраст INK на белых клавишах.
6. Сравнивать бок о бок с фото реальной техники (TE OP-1 field, TP-7, Braun T3, Nothing Phone) крупными кропами.

Уроки (2026-10-22, вечер):
- Пластик — **Metallic строго 0** (было 0.2–0.35 «для искры» → дешёвый пластико-металл). Металл только 0 или 1.
- Тёмная тема: холодный голубой rimW (как в туториале SILVER PUNK «Procedural plastic»), мелкое зерно bump ×2.
- Пробовали большой софтбокс над устройством (`sheen`) — плоские клавиши отражают его серой пеленой, подписи теряются. НЕ делать.
- Пробовали AgX — тёмная тема слишком тёмная. Остался Standard.

Сделано позже тем же вечером:
- **Окно — фиксированные размеры** S 1280×720 / M 1600×900 / L 1920×1080 (настройки → «Oyna hajmi»; по умолчанию
  самый большой, что влезает в рабочую область). Rust `set_size` + `lock_size` (min = max размер, иначе Windows рисует
  белую рамку у не-resizable окна без рамки). Кнопка «развернуть» и F11 — полный экран. Пользователь жаловался, что
  растягивание «дёргается, как натянутая картинка» — НЕ возвращать свободный ресайз.
- **Кнопка CHAT убрана из меню** (чат всегда виден справа). Меню: ASOSIY 0, QIDIRUV 1, KUTUBXONA 3, PROFIL 4
  (id экранов прежние), шаг клавиш 104 px.
- **Переходы экранов**: вместо шторки — плавное гашение/проявление с лёгким размытием (`shutter()` в app.js).
- **Материал `Ctx.plastic()`** по рецепту SILVER PUNK: roughness = noise→ramp(0.3..0.8), bump = noise × multifractal
  (invert), `dome` — выпуклый колпачок клавиш через наклон нормали на верхней грани. Сканы ambientCG теперь только
  в roughness (normal-карты отключены). Стальные кантики `Ctx.ring()` + `STEEL` вокруг отсека и LCD.
